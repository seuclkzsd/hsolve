# P40 original-pencil residual enclosure

The final frozen candidate is `v3/band_backend.hpp`. It embeds exactly the text in `v3/residual_enclosure.inc`. The control combines P37 compensated correction with P39 per-sector factor reuse; the enclosed variant changes two internal linear-solve acceptance calls. The existing threshold is still 1e-12. The requested-shift probe, lazy-MUMPS fallback verification, eigenpair verification, rank checks and original-pencil exact inertia certificate remain in force.

For each component of r = b - (alpha A + beta B)x, the SIMD loop accumulates a compensated dot product and an error bound. A scaled coefficient is split into its rounded value and its FMA product error. Real and imaginary components each receive four real products per complex matrix entry. The initial RHS is an exact product by one, giving m = 4 * entries + 1 terms. The reference is Ogita, Rump and Oishi, *Accurate Sum and Dot Product*, SIAM J. Sci. Comput. 26(6), 1955–1988 (2005), Algorithm 5.8 (Dot2Err) and Corollary 5.9:

- Author PDF: https://www.tuhh.de/ti3/paper/rump/OgRuOi05.pdf
- DOI: https://epubs.siam.org/doi/10.1137/030601818

For u = 2^-53, the code uses delta = fl(m*u/(1-2*m*u)), accumulates the absolute correction sum e, and computes the published enclosure around the final fl(hi+lo). Its underflow allowance is 8*min_normal, conservatively exceeding the paper's 3*min_subnormal/u = 6*min_normal. Range checks limit nonzero scaled coefficients, x and RHS components to [1e-100,1e100]; zero results from nonzero scaling operands are rejected. Dot lengths above 2^20 are rejected. These gates avoid overflow in the product/sum path and underflow in nonzero high coefficient products. FMA recovers coefficient product errors; low-part products retain the theorem's underflow allowance.

The componentwise denominator is the original-pencil positive sum |b|_1 + sum |alpha*a|_1 |x|_1 + sum |beta*b|_1 |x|_1. The rounded positive accumulation uses a lower bound multiplied by 1 - 8*(m+8)*double_epsilon. This deliberately exceeds the rounding-operation count for scaled coefficients, component magnitudes, products and summation. The numerator is |computed real residual| + |computed imaginary residual| + both error radii, inflated by 1 + 8*double_epsilon; the final quotient is rounded upward using nextafter. Any unsupported range, nonfinite result, zero denominator, non-nearest rounding or flush-to-zero mode returns to the original long-double residual. An upper bound <=1e-12 is sufficient for acceptance; a larger bound triggers the original long-double decision.

v1 passed numerical checks but disassembly found implicit vector FMA contraction in the bound formula. v2 adds GCC's function-local fp-contract=off, leaving explicit product-error FMA instructions intact. v3 checks MXCSR in both parallel loops as well as on entry. Final disassembly is retained for all three exercised objects and checked for unintended vector fused multiply-add instructions.

The initial v3 boundary harness failed to include omp.h. A subsequent harness assumed a worker's modified MXCSR survived into the next parallel region. A dedicated probe showed that this gpu02 libgomp resets that worker's rounding controls on entry to the next region. The final harness explicitly verifies the observed reset. It does not establish coverage of a persistently abnormal mode inside a running worker. Caller-mode and FTZ cases still exercise rejection; production worker checks remain present. All failed harnesses and their logs are retained.

Independent tests use both long-double sparse calculations and Decimal(90) calculations from original loaded matrix coefficients, including the loader's documented Hermitian normalization. Numerical tests support the implementation and guard behavior; the analytical argument and actual instruction rounding remain essential. No dense matrix is created by the solver. Existing small dense-spectrum oracles are confined to test data.
