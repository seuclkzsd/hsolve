# 困难场景对比：hsolve 与 SLEPc

电磁仿真里的特征值问题，难点往往不在规模，而在谱的形状：重特征值、位移恰好落在特征值上、旋度-旋度算子
在 0 处的巨大零空间、B 不定的波导问题、需要一个不漏的整段区间、复厄密的周期结构。本页把这些场景逐一做成
可复现的算例，让 hsolve 与开源标杆 SLEPc（Krylov-Schur + 位移反演 + MUMPS）在同型号节点、同样 16 核与 32 GiB
下求解，每一次结果都交给与求解器无关的评测程序判定对错。SLEPc 按两种方式使用：典型用户的**常规用法**，以及
为每个算例单独调过参数的**逐例调优**。物理量（谐振频率、传播常数）与解析解的对照见[物理场景](物理场景.md)。

![各困难场景的求解时间，未通过独立评测的结果以红叉标出，右侧注明出错的方式](../images/scenarios.png)

## 结论

这些场景里 SLEPc 的问题大多不是「算不动」，而是「结果不对」：重特征值少了副本、位移落在特征值上时残差失控、
复厄密问题做不了谱切片——其中一部分漏解的运行还报告了成功。σ = 0 的低频查询是另一种情况：SLEPc 按字面返回
σ = 0 最近的特征对，也就是梯度零空间的零模，要得到其上的物理谐振需要额外输入。对 B 正定的问题，hsolve
在窗口两端做 LDLᵀ 分解、用 Sylvester 惯性数出窗口内应有的特征值个数，找到的个数对不上就继续求，零空间的维数
也由惯性数出并排除；B 不定的波导问题由与求解器无关的参考解核对。本页 hsolve 的每一次运行都通过了评测。
逐例调优能让 SLEPc 在一部分场景里也得到正确结果，两者都正确时的时间比与 hsolve 更慢的场景照实列出
（下面的数字都由脚本从原始记录统计）。

## 方法

**三个求解器**（每个场景内交错运行，每次重复轮换先后顺序）：

- **hsolve**：命令行 `build/release/hsolve`，算例自带的配置（目标、容差 1e-10），完备性证书为默认的 `exact`。
  结构识别快速路径（可分离笛卡尔 / Bloch 旋度-旋度候选，`src/eigen/separable_*`）在全部运行中关闭：B 正定的问题
  加配置 `"method": "shift_invert_lanczos"`——这正是默认 `auto` 在 B 正定时选用的方法，唯一的区别是跳过结构候选
  （`src/driver/definite.cpp` 只在 `auto` 时尝试它）；每次运行都检查报告里的 `candidate_source` 为 `iterative`。
  B 不定（GHIEP）的问题没有这条路径，配置不变。「最低 k 个物理模」场景另加 `zero_filter_tol = 1e-8`
  （按惯性排除零空间，`docs/FORMATS.md` §2）。
- **SLEPc 常规用法**：`tools/bench/baseline_slepc.py`，Krylov-Schur + 位移反演，K = A − σB 用 MUMPS 分解
  （实数 LDLᵀ，复数 LU），SLEPc 与 MUMPS 的默认参数，1 个 MPI 进程 × 16 个 OpenMP 线程，收敛判据与 hsolve 相同
  （后向误差 ≤ 1e-10）。
- **SLEPc 逐例调优**：`tools/bench/tune_slepc.py` 为每个算例在 16 核上搜索出的最快有效配置（进程/线程布局、
  `ncv`、MUMPS 排序与 BLR 等），以及之后为修复其失败而收紧的配置，合并在
  [`results/showcase/slepc_tuned_profiles.json`](../../results/showcase/slepc_tuned_profiles.json)。
  此前没有逐例配置的场景，本次用同一个调优程序在 16 核上补做了调优（`tools/showcase/run_all.sh tunes`，复数
  场景 `tune-complex`）：从默认配置出发，默认配置无效时先在精度组里找能通过评测的配置（`eps_tol` 收紧到
  tol/10；`nev` 加到 k+2、k+4、2k、3k，后两者针对整组高重数能级；`ncv` 3k），再依次搜索进程/线程布局、MUMPS
  排序、MUMPS 选项、BLR、Krylov 子空间维数与重启参数，最后对候选配置交错重复确认（各 5 次）。多进程 MUMPS
  的结果每次运行不完全相同，同一配置可能时而有效时而无效：调优中见到这种情况，或正式测量中所选配置出现这种情况
  时，按调优程序的规则把该场景当作随机失败重新调优，每个候选交错确认 20 次、全部有效才算有效。每次调优的全部试验（配置、
  求解时间、评测结论）提交在 `results/showcase/tuning/<场景>.json`（[目录](../../results/showcase/tuning/)），
  汇总在 [`slepc_tuning.json`](../../results/showcase/slepc_tuning.json) /
  [`slepc_tuning.md`](../../results/showcase/slepc_tuning.md)。调优配置按算例保存，所以两个近奇异位移场景各有
  一个派生算例（同一组矩阵与参考谱，配置目标改为该场景的 σ），分别调优。调优找不到有效配置的场景沿用同类问题
  （问题类型 + 目标方式）的调优配置；该配置就是默认配置时，表中写「默认配置（无该算例的调优配置）」。

**判定**（`tools/eval`，与求解器无关）：每个返回的特征对重新计算后向误差（保守的 2-范数估计），
与参考谱逐一匹配，检查是否漏掉了目标要求的特征值、是否有参考谱里不存在的特征值（伪特征值）、
是否有重复的特征向量。一次运行**有效**当且仅当：正常退出、求解器自称成功、评测通过。一个场景下某个求解器
**正确**当且仅当它的每一次重复都有效。表中未通过的类别：

- **漏解**：目标集（σ 最近的 k 个，或区间内全部）里有特征值没有返回，例如重特征值少了副本；
- **伪特征值**：返回了参考谱里没有的值（零空间的零模除外，见下一类）；
- **返回零空间模**：「最低 k 个物理模」场景按字面是求 σ = 0 最近的 k 个特征对，这个问题的答案就是梯度零空间
  的精确零特征对（|λ| ≈ 1e-16）。参考谱只列物理谐振，所以这类运行判为未通过，但它不是数值错误：SLEPc 回答的
  是字面上的问题，没有选项能在不提供额外输入（离散梯度矩阵作收缩空间，或给出区间）的情况下排除零空间；
  hsolve 用 Sylvester 惯性数出零空间维数并排除（`zero_filter_tol`）。这类运行不计入「静默错误」；
- **残差超限**：有特征对的后向误差超过 1e-10，括号里是评测程序重算的最大值。SLEPc 的收敛判据设为同一个
  后向误差（`EPS_CONV_NORM`，容差 1e-10），这类运行 SLEPc 自己也报告不成功（包装脚本用 `EPSComputeError`
  复核每个返回的特征对）；
- **报错退出 / 不支持**：没有可用结果，原因（库的报错）见「未通过的运行」。

**静默错误**指求解器自报成功、评测却未通过的运行（返回零空间模的除外）：这样的错误只有完备性计数或对照参考谱
才能发现。「未通过的运行」一节逐条列出每个求解器自报成功的次数。

### 完备性证书是什么

hsolve 对 B 正定的问题给出的不是「收敛了」，而是「这个窗口里一共有多少个特征值、我都找到了」：在窗口两端做
LDLᵀ 分解，由 Sylvester 惯性定律数出窗口内特征值的个数，与找到的互不相同的特征对个数比较。重特征值的
副本即使残差再小也逃不过这个计数。

### 复厄密问题（Bloch 周期结构）

周期结构加 Bloch 边界条件后矩阵是复厄密的。hsolve 把复厄密 LDLᴴ 嵌入为两倍规模的实对称问题，惯性计数照常
可用，因此「σ 附近最近 k 个」和「区间内全部」都附带证书。SLEPc 在复数版本里用 MUMPS LU 分解 K = A − σB
（PETSc 的 MUMPS Cholesky 接口只支持复对称，不支持复厄密），LU 不提供惯性，谱切片因此无法进行。上表
「Bloch 周期单元：区间内全部特征值」一行的 SLEPc 结果来自包装脚本的拒绝；为了确认这不是包装脚本的限制，
`tools/showcase/slepc_probe.py` 直接调用 PETSc/SLEPc 分别尝试 Cholesky 与 LU，库本身的结果见上面「未通过的运行」
（原始记录 `results/showcase/raw/slepc-probe.json`）。
